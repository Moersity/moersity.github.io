技术日报

每天筛选 AI 推理系统、Golang、Rust 与 Kubernetes 的关键变化。重工程判断、可落地实践和一手来源，不堆新闻。

2026-09-07

KV Offload 的正确性边界：只存真实写入、未来可达且仍有人等待的状态

vLLM 连续修复终止 Token、SWA 分段和异步取消三类 Offload 错误；SGLang 则把缓存路由升级为分桶策略，并定位 ROCm 权重加载的 Eviction Storm。

2026-09-06

推理服务开始收缩故障域：坏请求、断链与半成品缓存不再拖垮进程

最近 48 小时最值得关注的不是新版本，而是 vLLM 与 SGLang 同时把输入校验、传输失败和缓存发布从引擎级故障降为请求级失败。

2026-09-05

CUDA Graph 的真正边界，是指针生命周期、跨 Rank 形状与隐式同步

vLLM 与 SGLang 的最新主干修复同时指向同一件事：图捕获不仅是 Kernel 优化，还必须冻结 Workspace、统一分布式形状，并清除热路径上的 Device Sync。

2026-09-04

外部 KV 缓存走向闭环：链路、路由与失败边界同时补齐

SGLang 完成 Mooncake External Linker 端到端接线，并把路由策略和 P/D 启动失败显式化；vLLM 则在避开 Fork 竞态后重新引入渲染预热并发。

2026-09-02

KV Cache 开始跨异构 TP 共享，但物理布局与信任链必须先对齐

vLLM 推进 Mooncake 异构 TP 共享，同时修复物理块长度导致的静默覆盖；SGLang 用实测定容 CUDA Graph 池，KServe 与 Kueue 则分别启动缓存验证和动态配额的契约建设。

2026-08-31

推理入口开始补复杂度预算，通信与数值路径继续暴露静默风险

vLLM 与 SGLang 同时限制可被放大的请求字段；更深层的风险则来自 FP16 中间格式、CUDA Graph 显存预算，以及名为异步却仍阻塞或失去 Buffer 所有权的通信接口。

2026-08-30

DCP 把 KV 传输推入布局优化，推测解码开始偿还随机状态债务

vLLM 与 SGLang 同时推进 DCP/P-D 数据路径，但更值得警惕的是：推测解码的随机流、跨 Rank 状态和外部缓存边界仍在暴露正确性缺口。

2026-08-29

推理系统的下一轮收益，来自把数据移动藏进计算窗口

vLLM 把远端 KV 提交后移以覆盖 GPU 计算，SGLang 修复分层缓存的跨流与租户隔离风险，KServe 则补上 P/D 拓扑中真正执行 KV 传输的连接器。

2026-08-28

版本发布后，真正的生产风险藏在默认切换与状态所有权里

vLLM 主干默认转向 Model Runner V2，却同时回退一次会触发 Fork 死锁的预热优化；SGLang、KServe 和 Kueue 的新改动则共同指向负载、缓存、适配器与配额的真实所有权。

2026-08-27

vLLM 0.28 与 Kubernetes 1.37 同日到位，默认值和调度边界一起变化

vLLM 把分层 KV、E/P/D 与新模型运行器推向可用，同时修改批处理和依赖默认；Kubernetes 1.37 则让 Scale-to-Zero、Gang Scheduling 与 DRA 更贴近 AI 集群。

2026-08-25

主干无新版本，但三处生产边界值得立即补测

vLLM 补齐音频输入限额并修复 TP 推测解码初始化，SGLang 修复回退后的循环状态串扰；这些都已合入主干，但尚不是新的稳定版。

2026-08-22

SGLang 0.5.18 升级栈底，确定性与冷启动必须重新验收

SGLang 更新 Torch、Triton、FlashInfer、缓存目录与多项默认行为；Kubernetes 发布稳定补丁和 1.37 rc.1，Rust 1.98 又显式引入可重排但非确定性的浮点 API。

2026-08-19

KV Cache 成为移动状态，调度开始直接承载多档 SLA

今天最值得关注的是主动 KV 迁移与多级优先级调度：前者把移动性预测引入推理状态管理，后者把商业服务等级落实到 Headroom、迁移与尾延迟。

2026-08-18

调度开始同时解决确定性、阶段复用与内存层级

今天没有值得追逐的框架大版本；更重要的是，推理调度正从排队与批处理扩展到执行形态控制、RL 跨阶段复用和 MoE 权重的数据路径设计。

2026-08-16

低变化窗口，更该补齐配额与回归门禁

最近 24–48 小时主流推理与语言项目没有新的正式大版本；今天把注意力放到 Kueue 的配额正确性、真实工作负载评测和生产升级纪律。

2026-08-13

RL Rollout 调度开始超越 Prefix Locality

今天最值得关注的是混合 RL rollout 对 KV 容量与驻留时间提出的新调度要求，以及集群级持续性能回归正在成为推理基础设施的基本能力。

2026-08-12

大版本之后，生产升级先看回归门禁

vLLM 0.27.1 紧随大版本发布，SGLang 继续交付全栈模型路径；生产评估应把正确性、冷启动和尾延迟与吞吐并列。

2026-08-11

推理系统进入可运维的集群级工程阶段

vLLM 与 SGLang 同时加强 Rust 前端、KV 生命周期与故障恢复，竞争重心从单点性能走向完整 Serving 链路。
